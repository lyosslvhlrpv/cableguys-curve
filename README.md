## Overview

Cableguys Curve is a versatile distortion and waveshaper with a built-in LFO editor, enabling complex modulated distortion patterns synchronized to your DAW tempo.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Cableguys Curve** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Waveshaper** | Freely drawable transfer curve for custom distortion characteristics |
| **Sync LFO** | Tempo-synced LFO modulates the waveshape for rhythmic distortion |
| **Multiband Mode** | Split signal into bands and apply independent waveshaping per band |
| **Oversampling** | Up to 8x oversampling reduces aliasing for clean high-gain settings |
